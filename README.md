# سوق السبت - بيت الحرفي (Souk Essebt)

المنصة الرقمية الجامعة لحرفيي ولاية ورقلة، مصممة خصيصاً لتكون دليلاً مهنياً مبسطاً وسهل الإدارة دون تعقيدات برمجية.

## 🌟 أهداف المشروع
- توفير دليل موثوق يربط بين المواطنين وحرفيي بلديات ورقلة الثماني.
- دعم الاقتصاد المحلي وتمكين أصحاب الحرف والمهن.
- إدارة المحتوى بشكل يدوي وآمن من قِبل فريق العمل عبر واجهات خفيفة ومرنة.

## 🛠️ هيكل الدليل
- **البلديات المدعومة:** ورقلة، الرويسات، عين البيضاء، حاسي مسعود، حاسي بن عبد الله، سيدي خويلد، البرمة، والنقوسة.
- **القطاعات المهنية:** يغطي الدليل 9 قطاعات رئيسية (البناء، الكهرباء، السباكة، النجارة، الخياطة والتطريز، صيانة الأجهزة، الحدادة والميكانيك، الخدمات الرقمية، والحرف المتنوعة).

## 🚀 طريقة التشغيل والاستضافة
